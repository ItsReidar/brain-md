## What's new in 1.8

### Delete with ⌘⌫, safely
Click a note in the sidebar and press ⌘⌫ (or **File › Move to Trash**) to delete it. Deleted notes, attachments and folders now go to the macOS Trash, so Finder's **Put Back** restores them; nothing in Brain.md deletes permanently any more, AI assistants using the `delete_note` tool included. While you're typing, ⌘⌫ still deletes to the start of the line.

### Easier clicking in the sidebar
The whole highlighted row of a note or folder now responds to clicks, not just its name, in the sidebar, search results and tag lists.

### A friendlier README
The project page is shorter and easier to scan.
