## What's new in 1.7

### Native macOS tabs
Note tabs now use the macOS tab bar. Open a note in a new tab with **Open in New Tab** or ⌘-click, or press ⌘T (or the tab bar's **+**) for an empty tab. Each tab is named after its note and keeps its own unsaved edits, so you can switch freely; ⌘W closes a tab. Drag tabs to reorder them, or pull one out into a window of its own to see two notes side by side. Your tabs still come back when you reopen Brain.md.

### Opening files
Markdown files opened from Finder or with the `brain` command each open in their own tab, and a file that's already open brings its tab to the front. `brain notes.md todo.md` opens both.

### Good to know
AI Chat no longer reopens by itself after a relaunch; open it with ⇧⌘J.
