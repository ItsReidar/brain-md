## What's new in 1.4

### Open notes from the terminal
The new `brain` command opens Markdown files in Brain.md, just like double-clicking them in Finder: `brain notes.md` opens a note, `brain` on its own opens the app. A file that doesn't exist yet is created, so `brain new.md` starts a new note; if you close it without writing anything, Brain.md moves it to the Trash. Homebrew installs the command with the app. Without Homebrew, link it yourself:

    ln -s /Applications/brain-md.app/Contents/Resources/brain /usr/local/bin/brain
