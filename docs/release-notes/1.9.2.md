## What's new in 1.9.2

### Fixes
- **Deleting notes in a OneDrive vault.** macOS doesn't let apps move files that OneDrive has synced to the Trash, so deleting them failed with a permission error. Brain.md now does what Finder does: it asks whether to delete the note immediately, and only does so after you click **Delete**. OneDrive usually keeps a copy in its online recycle bin. New notes that haven't synced yet still go to the Trash as before. (Some 1.9.1 downloads didn't include this fix; 1.9.2 does.)
- **More resilient release builds.** Background file indexing or locks on the build folder no longer stop a release build.
