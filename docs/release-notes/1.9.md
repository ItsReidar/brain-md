## What's new in 1.9

### More for your AI assistants
Brain.md's MCP server now has 16 tools. Six are new:
- **`create_folder`** and **`list_folders`**: assistants can organize your vault into folders, and see empty ones too.
- **`rename_note`**: rename a note or folder in place.
- **`search_by_meaning`**: assistants can use the same on-device search by meaning as the sidebar (needs a search model in **Settings › Local AI & Voice**).
- **`get_open_note`** and **`open_note`**: assistants can read the note you're looking at, unsaved edits included, and open a note for you in a new tab.

### Fixes
- **Read-only mode now really protects your notes.** The **Read-Only** switch in **Settings › MCP Server** didn't block anything before; with it on, assistants can now read and search but can no longer create, change, rename, move or delete notes and folders.
